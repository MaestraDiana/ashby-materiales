# Diagrama de Ashby — Selección de Materiales

Herramienta interactiva de selección de materiales basada en la metodología de diagramas de Ashby. Desarrollada en HTML5 puro, funciona completamente sin conexión a internet y sin dependencias externas.

## ¿Qué hace?

- Visualiza tres gráficas de propiedades mecánicas para comparación de materiales
- Calcula el índice de rendimiento a partir de los requisitos de diseño ingresados
- Posiciona el resultado como un punto en el diagrama correspondiente
- Muestra una línea límite configurable para filtrar materiales que cumplen el criterio

## ¿Cómo usarla?

Descarga el archivo `ashby_simplificado.html` y ábrelo en cualquier navegador. No requiere instalación ni conexión a internet.

O úsala directamente en línea:  
👉 https://maestradiana.github.io/ashby-materiales
